# AGENTS.md

For Codex, Cursor and every agent that reads `AGENTS.md`. The instructions for working
on nopekit live in one place, [`CLAUDE.md`](CLAUDE.md) — Claude Code reads it by that
name, and a copy here would drift from it. Read it whole before you change anything:
its invariants, house rules and the commits a change must carry hold for every agent.

**Using** nopekit (rather than working on it)? The skill in `skills/nopekit/` is the
entry point, and `nopekit doctor` is the first command to run when confused. How each
host installs the plugin — Claude Code, Codex, Cursor — is in the README's
*Get started*.
